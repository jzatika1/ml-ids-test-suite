# UCC 2024 Context

This repository supports the work presented in:

**Improving IDS Performance with XGBoost Hyperparameter Optimization and Real-Time Analysis**  
Anthony Zatika and Joel Coffman  
2024 IEEE/ACM 17th International Conference on Utility and Cloud Computing (UCC 2024)  
Pages 201-210, DOI: `10.1109/UCC63386.2024.00037`

The project focuses on practical network intrusion detection with engineered traffic features, XGBoost training, hyperparameter optimization, and realtime Zeek `conn.log` analysis.

## Scope

The UCC work is the network IDS component. It is intentionally separate from the newer AICCC autonomous-agent alliance project, which combines this IDS capability with additional routing, malware-analysis, audit, and oversight components.
